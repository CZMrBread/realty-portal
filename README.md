# Realty portal
A realty portal with import in format of [Sreality.cz](https://www.sreality.cz/)

## Structure
- [Server](Server/README.md) - Backend code (asp.net core)
- [Client](Client/README.md) - Frontend code (Blazor WebAssembly)
- [Shared](Shared/README.md) - Shared code (DTOs, Enums, etc.)

the app is using Postgress database with Entity Framework Core
